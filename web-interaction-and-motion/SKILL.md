# 网页交互动效与工具选择

> 验证状态：尚未通过执行新的网页项目验证；方法根据 V09、V11、V14 的转写，以及全部抽取的联系表和关键帧，于 2026-11-27 重建。
> 视频展示了方法和工具边界，但没有提供完整的实现代码库。

先把用户动作、画面反应和时间关系说清楚，再选择工具。生成式视频适合做形态和氛围，代码适合做位置、时间、路径和鼠标控制；逐帧角色则用素材处理和前端映射把视频变成可交互的精灵图。

## 步骤

### 1. 用可观察的语言命名动效

不要从“做一个酷炫效果”开始。先写触发器、反应对象、运动方式和结束状态：

```text
触发器：鼠标滑过 / 点击 / 悬停 / 滚动 / 定时
反应对象：背景 / 文字 / 图片 / 卡片 / 角色 / 3D 物体
运动方式：流体扰动 / 透视揭示 / 粒子卷动 / 折射 / 位移 / 弹性拉伸
结束状态：恢复原位 / 停在当前帧 / 播完后回到起点 / 跟随时间线继续
```

V09 逐项给出过这些可复用名称：流体扰动、流体蒙版透视、透镜跟随双语揭示、鼠标驱动三维碰撞、点击触发产品展示、点击触发空间转场、粒子卷动、液体折射、像素网格错位、鼠标跟随聚光、布料模拟、弹性拉伸。[t=0:00]–[t=1:08] V09

这些是动效词汇，不是要求你复制同一网站。先把需求翻译到同一词汇表，再让 AI 选择实现方式。

### 2. 在生成式素材和代码控制之间做判断

- 只关心形态、质感、颜色和整体氛围时，先用生成式视频或图像做素材。[t=0:00]–[t=0:32] V11
- 需要按固定周期变化、沿指定路径移动、响应鼠标或严格控制外观时，用代码生成或控制。[t=0:32]–[t=1:02] V11
- 两者可以组合：先生成素材，再用代码安排出现时间、位置、衔接和交互。[t=1:02] V11

✔ 成功：需求中能明确区分“素材长什么样”和“素材何时、在哪里、如何响应”。

### 3. 为视频输出选择排版工具

根据已有资产和工程结构选择：

- **Remotion**：把样式、出场动作、文字和图片的帧位置做成可重复模板；适合已有模板只换内容和时间。[t=1:02]–[t=2:04] V11
- **HyperFrames**：用更接近网页的方式排列文字、图片和视频，再安排它们出现；适合已有网页动画或更偏页面结构的工程。[t=1:02]–[t=2:04] V11

不要先背一长串工具名。先告诉 AI 想要的效果和已有工程，让它在保留原有模板的前提下给出小段演示；已有工程优先沿用原工程。[t=6:28]–[t=6:45] V11

### 4. 为动作和布局变化选择工具

- **CSS**：卡片悬停抬高、移开恢复等简单前后状态；用过渡时间控制节奏。[t=2:04]–[t=2:35] V11
- **原生 JavaScript**：读取鼠标位置，计算元素偏移和方向。[t=2:35]–[t=3:08] V11
- **Motion**：中间卡片展开、旁边卡片让位等布局变化；减少手动计算每个元素位置。[t=3:08] V11
- **GSAP**：多个动作排在一条时间线，控制谁先动、谁后动、哪些同时动，并可与滚动进度关联。[t=3:08]–[t=4:12] V11

如果 CSS 和原生 JavaScript 已经能清楚表达少量状态，不要为了工具名而增加依赖；当动作数量和时间关系变多，再用 Motion 或 GSAP 组织复杂变化。

### 5. 为画面呈现选择 Canvas 或 Three.js

- **Canvas**：把图片、文字和多层素材画到二维画布；适合按鼠标方向选择图片、做前后叠放和二维推进。[t=4:12]–[t=5:20] V11
- **Three.js**：需要真实物体、灯光、相机、自由视角或按位置折叠的三维场景；必须先搭好物体，而不是把一张图片自动当成立体模型。[t=4:12]–[t=5:20] V11
- **组合**：JavaScript 负责根据鼠标选图，Canvas 负责显示选中的图片；这是逐帧角色跟随鼠标的清晰分工。[t=4:12]–[t=4:55] V11

遇到“文字像贴上去”或“色块没有跟着建筑面折叠”的问题时，让 AI 检查文字是否跟随表面、角度是否正确、遮挡关系是否成立，再提出单项修改。[t=5:20]–[t=6:28] V11

### 6. 制作逐帧角色素材

使用逐帧方案时按以下顺序：

1. 生成一段绿幕角色视频；先把关键姿势和第一帧图做好。[t=1:02]–[t=2:11] V14
2. 把视频逐帧拆成图片。视频示例中，6 秒约拆出 145 张；这是来源视频的示例值，实际数量取决于帧率。[t=1:02]–[t=1:25] V14
3. 把背景抠掉，只保留角色；绿幕要颜色统一、没有渐变，也不要有地面或人物阴影。[t=2:11]–[t=2:40] V14；关键画面显示“整个背景都是绿幕”。
4. 每 16 张小图拼成一张精灵图，网页按索引显示其中一格。视频另一个示例把 290 张小图压成 19 张大图，以减轻网页加载。[t=1:25]–[t=2:11] V14

✔ 成功：角色帧顺序连续，背景抠除干净，精灵图索引能从首帧走到尾帧，页面加载的文件数量明显少于单独加载每张图片。

### 7. 让生成素材适合后期处理

- 背景使用纯绿且不渐变；如果角色衣服本身是绿色，改用蓝色背景。[t=2:11]–[t=4:29] V14
- 明确左右方向是“以屏幕观看者为准”，避免生成工具反转动作。[t=2:11]–[t=3:18] V14
- 只改需要运动的部位，衣服和站立位置保持稳定。[t=2:11]–[t=3:18] V14
- 复杂动作要把手势、每秒动作、镜头是否移动和禁止动作写清楚；动作越精确，提示越要按时间拆开。[t=3:18]–[t=4:29] V14
- 复杂舞蹈可以使用动作参考或深度白模，再叠加角色外观；固定相机、人物居中、全身入镜，并保持参考视频的宽高比。[t=4:29]–[t=5:41] V14

### 8. 选择角色交互模式

根据用户期望选择一种，不要把三种模式混在一起：

1. **鼠标跟随**：鼠标方向映射到角色帧，适合让角色持续盯着或跟随鼠标。[t=5:41]–[t=6:50] V14
2. **悬停 / 点击反馈**：停留或点击后播放一段动作；可在代码中补一个回弹或恢复动作。[t=5:41]–[t=6:50] V14
3. **音乐同步**：按音乐播放时间选择动作帧，动作播放完后切回背景音乐，保持页面听感连贯。[t=5:41]–[t=6:50] V14

给 AI 的需求至少包含四项：交互模式、素材是哪段视频和哪一段、背景颜色、拆多少张和每多少张拼成一张大图，以及鼠标方向或点击后对应哪些帧。[t=6:50]–[t=7:28] V14

### 9. 做交互回归检查

检查每个状态的触发、响应、恢复和边界：

- 鼠标停住时，角色是否停在合理帧；跳过闭眼帧，避免角色长时间闭眼。[t=5:41]–[t=6:05] V14
- 点击动作是否完整播放，回弹和恢复是否自然。[t=5:41]–[t=6:20] V14
- 循环动作首尾是否回到同一姿态；鼠标跟随的方向是否没有左右翻转。
- 复杂三维场景中，文字、色块和遮挡是否与表面同步。[t=5:20]–[t=6:28] V11
