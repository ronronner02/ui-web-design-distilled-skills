# 沉浸式视觉体验的设计与制作方法

> 验证状态：方法根据 V13 转写和画面检查，于 2026-11-27 重建，V10 和 V12 保留为展示参考。尚未通过新项目执行验证。
> 下文抽象作者的过程和判断规则；时间戳指向原案例，不代表已验证所有迁移场景。来源没有提供完整实现代码。

先把体验说清楚，再按体验拆素材、试组合、找出失败原因。作者真正反复调整的是素材能否用于当前构图、前后空间如何接续，以及同一主体怎样贯穿多个场景。围绕这些问题组织制作，主题、对象、素材数量和工具随当前项目确定。

## 使用方式

从现有需求中确定：希望用户感受到什么、内容如何展开、已有素材是什么、关键主体有哪些、哪些变化需要用户控制。先处理影响体验的结构问题，再提高素材精度；角色制作、动作参考、色幕和循环仅在需要时启用。

本方法适用于需要空间层次、场景连续性或视觉叙事的网页。原始题材和参数仅承担来源追溯；需要核对作者示例时，阅读[来源证据](references/source-evidence.md)。

## 工作方法

### 1. 把体验意图写成可以拆解的关系

说明用户如何观看或推进，哪些内容保持在视野中，哪些内容在何时出现或接上。先定义可观察的体验，再决定怎样实现。[t=0:00]–[t=1:05] V13

可以用以下结构承接当前项目；其中输入方式和展开方向根据需求填写：

```text
体验目标：<用户应感到什么，主要看懂什么>
观看与推进：<视线或场景怎样变化，由什么控制>
空间关系：<哪些内容在前、在后、包围或遮挡其他内容>
内容接续：<当前内容经过或结束后，什么接上>
稳定特征：<哪些主体、外观或视觉规则持续保持>
```

✔ 成功：能够从体验说明推导出素材和层次的职责；所需内容有明确用途。

### 2. 按用途拆素材，再判断是否适合组合

把素材按承担的作用归类，例如环境背景、空间边界、过渡层、关键展示对象。实际需要几类、每类几份，由当前体验决定；来源中的分类数量是作者针对该项目的拆解结果。[t=0:32]–[t=1:05] V13

筛选时同时看视觉质量和使用条件：是否留出需要的观看区域，轮廓能否与前后内容衔接，关键对象是否完整，还缺少什么。先选适合组合的素材，再补缺口。[t=1:05]–[t=2:15] V13

“中心留入口”只适用于需要向前穿越的构图。其他体验应按自己的视线、移动和内容接续方式决定留白与边界。

✔ 成功：每份素材都能说明在页面中的用途；知道哪些可以使用，哪些需要重选或补充。

### 3. 从失败画面诊断关系，避免只换工具

用一小段足以检查目标体验的场景试组合，定位究竟是素材、空间还是衔接的问题。作者曾比较多种版本，以下诊断来自这些尝试：[t=1:05]–[t=2:15] V13

- 画面像连续换图：检查是否只放大整图，导致关键轮廓在切换时重叠。
- 立体感有了但内容变形：检查素材是否被几何表面拉弯，破坏原本要保留的形状。
- 前一段结束后空间突然变平：检查后续环境是否及时接上。
- 单独对象都在，但场景显得空：检查维持包围感或连续性的环境层是否缺失。

把当前问题对应到可修改的关系，再选择调整方式。二维分层已经能表达目标时，可先用它验证；确有自由视角或真实几何需求时，再另行设计三维实现。后者属于应用时的方案选择，来源没有提供通用三维搭建流程。

✔ 成功：能指出“哪种关系造成了哪种观感”，下一轮修改针对该原因。

### 4. 用独立层安排遮挡和节奏（需要空间层次时）

把需要独立控制的环境轮廓、主体和装饰分成可组合的层。作者使用透明 PNG，并配灰度蒙版控制保留和透明区域；需要单独调节可见区域时可采用这种方法。[t=2:15]–[t=2:40] V13

按空间职责安排前后关系，分别控制位置、缩放和变化速度，让前层经过时后续内容已经接上，并保留观看方向。作者以近、中、远三层示范，迁移时按所需深度和内容密度决定层数。[t=2:40]–[t=3:27] V13

透明图像、蒙版和分层是为独立控制服务的；根据现有素材的透明信息和调整需要选择，不要求每份素材都增加蒙版。

✔ 成功：遮挡和速度形成明确层次，内容接续自然；用于控制的图层均有实际职责。

### 5. 固定需要贯穿场景的视觉主体（按需）

为跨场景重复出现的关键主体建立固定参考，并在后续生成中复用。作者用多视图保持人物和动物的外观；迁移到产品或其他对象时，同样先区分应稳定的特征和允许变化的部分。[t=3:27]–[t=4:00] V13

把信息分开说明：主体参考、当前环境、动作或状态、镜头条件。稳定项可包括轮廓、比例、颜色、材质；不需要跨场景重复主体时跳过该分支。

✔ 成功：场景变化后，关键对象仍可被识别为同一个；变化发生在本轮指定的部分。

### 6. 分开素材自身运动和页面中的位置变化（按需）

素材内部动作可以来自视频，素材在页面中的位置和推进则单独控制。需要合成时，准备可去除背景的素材，再与其他层组合；作者用纯色背景视频演示这个分工。[t=3:27]–[t=4:35] V13

需要循环或衔接时，先检查首尾。若存在跳变，可尝试作者使用的交叉衔接，并检查连接处的运动、位置和叠影是否符合目标。素材时长、背景处理和衔接方式按当前内容选择。[t=3:27]–[t=4:35] V13

✔ 成功：内部运动与页面布局可以分别调整，连接点没有破坏体验的明显跳变。

### 7. 把外观与运动解耦，先低成本试作再提高质量

需要参考动作时，分别提供主体外观和运动参考，避免仅用一段文字同时约束外观、动作与构图。作者用动作参考与形象图组合完成演示；没有此需求时直接使用已有素材。[t=4:35]–[t=4:55] V13

根据后续合成需要说明镜头是否固定、主体位置和必须保留的画面范围。核对参考与输出的宽高比，避免所需动作或伸出部分被裁切。[t=4:55]–[t=5:05] V13

先用较低成本的预览检查动作、构图、边界和连续性，通过后再提高最终输出质量。作者展示的具体分辨率是成本策略的案例，当前输出不要求采用同样规格。[t=5:05]–[t=5:20] V13

✔ 成功：关键体验和构图已经成立，后续提高质量不依赖重新解决结构问题。
