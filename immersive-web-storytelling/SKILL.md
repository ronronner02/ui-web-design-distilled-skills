# 沉浸式网页叙事

> 验证状态：尚未通过执行新的沉浸式网页项目验证；方法根据 V13 转写和画面检查，于 2026-11-27 重建，V10 和 V12 保留为视觉示例。
> 来源视频展示了创意制作方法，但没有提供完整的代码库。

沉浸感来自空间层级、遮挡关系、前后节奏和角色连续性。不要把一张完整图片不断放大后称为“进入画面”；先把素材拆成可控制的层，再安排谁挡住谁、谁先经过、谁接上下一段空间。

## 步骤

### 1. 先写“走进画面”的体验说明

用一句话描述用户如何移动，而不是先指定技术：例如“沿着壁画向前走，两侧和头顶被壁画包围，前方不断接上新的空间”。[t=0:00]–[t=0:32] V13

再明确四项：

- 运动方向：向前、横向、环绕或自由探索。
- 包围关系：两侧、头顶、脚下或全景是否持续出现内容。
- 新内容出现的位置：前方、侧面、上方或点击后。
- 用户控制：滚动、拖拽、鼠标、时间线或音乐节奏。

✔ 成功：AI 能根据说明提出素材分类，而不是只生成一张完整海报。[t=0:32]–[t=1:05] V13

### 2. 把素材按空间角色拆分

至少准备四类候选素材：

1. **密集背景或人物壁画**：构成主要环境。
2. **两侧和头顶的包围层**：维持空间边界。
3. **云朵、莲花、飘带等中景元素**：连接前后空间并制造遮挡。
4. **完整人物或关键叙事对象**：在空间里承担故事动作。[t=0:32]–[t=1:05] V13

每一类先生成多张，再按网页用途筛选。好看的单图如果中心没有可进入的开口，或者四周太完整导致视线无法向前，就不适合作为入口。[t=1:05]–[t=2:15] V13

### 3. 用分层构建空间，而不是连续放大整图

把壁画、洞窟轮廓、文字、人物和装饰扣成带透明区域的 PNG，并为每张图准备一张灰度蒙版，分别控制保留和透明区域。[t=2:15]–[t=2:40] V13

将素材分成近景、中景和远景：

- 近景先从用户身边经过。
- 中景提前接上下一段空间。
- 远景变化更慢，用来保持前进方向。[t=2:40]–[t=3:27] V13

为每层单独设置位置、缩放、速度和遮挡顺序。透明区域让用户看到后层，保留下来的轮廓会遮住后层；真正的穿越感来自环境被拆开后重新安排谁挡住谁、谁先出现、谁后接上。[t=2:40]–[t=3:27] V13

✔ 成功：前景经过后，中景已经接上，远景仍能提供方向；画面不会只像一张图片切换到另一张图片。

### 4. 保持关键角色的一致性

为贯穿多个场景的角色提前制作多角度参考图，例如正面、侧面和背面。之后每次生成新场景都带上同一组参考，避免人物脸部、服装和比例随场景漂移。[t=3:27]–[t=4:00] V13

把角色身份和场景描述分开写：

```text
角色参考：<固定角色参考图组>
场景：<本幕环境、色彩和空间位置>
动作：<本幕动作或姿态>
镜头：<距离、角度、是否固定>
```

✔ 成功：场景切换后，观众仍能把角色识别为同一个人或同一只动物。

### 5. 把动态素材合成进空间

可以把静态入口替换为一段带纯色背景的短视频，再与沙地、壁画和其他分层元素合成；视频中的商队示例约 6 秒。[t=3:27]–[t=4:35] V13

如果动态素材首尾连接会跳变，使用交叉衔接，并让运动方向、位置和背景层在连接点保持一致。[t=3:27]–[t=4:35] V13

这是来源项目的时长示例，不是固定要求；根据用户的停留时间和循环节奏重新决定时长。

### 6. 用动作参考制作角色舞蹈

把人物外观和人物动作拆成两类输入：

1. 提供原始舞蹈视频或动作参考，提取每一时刻的动作关系。
2. 提供前面准备好的角色形象图，让生成工具把角色替换到动作里。[t=4:35]–[t=4:55] V13

在提示中明确固定相机、人物居中、全身必须入镜，并让输出视频宽高比与动作参考保持一致，避免长袖、飘带或脚部出画。[t=4:55]–[t=5:05] V13

先用 480p 低清版本检查动作和构图，再进入 4K 高清版本；视频明确把低清试动作作为省成本的检查阶段。[t=5:05]–[t=5:20] V13

✔ 成功：低清预览中动作、人物位置和构图已经正确；只有在这些条件通过后才进入高清生成。

### 7. 用滚动或时间线驱动空间推进

把每层的位移、缩放和遮挡关系绑定到一个可控进度值。滚动驱动时，滚动位置对应空间推进；自动播放时，时间线对应空间推进。不要把全部内容烘焙成一段平面视频，否则无法对用户输入做响应。[t=0:00]–[t=0:32] V13；[t=4:35]–[t=4:55] V13

## 视觉检查清单

- [ ] 入口中心有向前看的空间，不被完整背景堵住。
- [ ] 近、中、远三层的速度、位置和遮挡顺序不同。
- [ ] 透明区域和灰度蒙版边缘干净。
- [ ] 前景离开后，中景及时接上，远景仍保留方向感。
- [ ] 关键角色跨场景保持脸、服装和比例一致。
- [ ] 动态素材首尾没有跳变。
- [ ] 动作参考和人物外观分开表达。
- [ ] 低清动作和构图通过后才生成 4K。
